Research · Turkish NLP

Where should LoRA go in a small Turkish model?

Same base model (Qwen2.5-0.5B), same 6.5k Turkish instructions, same steps and seed. The only thing that changes is where LoRA sits in the network and its rank. I trained 8 adapters plus a full fine-tune and measured Turkish quality, how much English was forgotten, and which weights actually moved.

  • MLP beats attention at equal parameters, and upper layers beat lower ones.
  • LoRA forgets less English than full fine-tuning: perplexity 15.6 vs 17.3 (base 14.7).
  • Found and fixed an untrained <|im_end|> token that kept models from ever finishing an answer.

LLM from scratch · RL

A 25.7M-parameter code model, from scratch

A small model inspired by GLM-5.3-Flash, written in plain PyTorch and pretrained on synthetic Python tasks. Then a reinforcement learning stage (RLOO) that runs the generated code and rewards only answers that actually work.

  • On a 64-question held-out test: 32 solved before RL, 53 after RL with answer-focused replay.
  • Diagnosed why plain RL made the model forget a task family it was not trained on, and fixed most of it.

Product · ML ops

Azula: investigate why an ML pipeline failed

An AI workspace for data and ML teams. Upload the logs of a broken pipeline and it finds the root cause (GPU OOM, schema drift, target leak), gives evidence and a fix, then lets several models debate the hypothesis.

  • Agreement between models is measured in code: same answer from different model families raises confidence, the same family repeating itself is flagged as an echo chamber.
  • Scored against a held-out gold set of four incidents.
